# Как сделать текущего робота стабильнее и прибыльнее (с ростом LP-резервов)

Ниже — выводы именно по вашей текущей логике `sinergia_bot.py` и симуляции 150 циклов.

## 1) Что показала проверка текущей логики

- При широком подборе параметров (21600 комбинаций) не найдено ни одной конфигурации, где одновременно:
  - `PnL > 0`,
  - растут оба LP-резерва (`CASRS/WMATIC` и `CASRG/WMATIC`),
  - максимальная просадка NAV <= 1%.
- Лучший найденный режим близок к нулю, но всё ещё в минусе (`-0.025735 MATIC` за 150 циклов).

Причина: текущая стратегия делает много оборота с малым edge и платит комиссии/проскальзывание чаще, чем зарабатывает.

## 2) Что менять в логике робота (приоритет)

1. **Фильтр edge перед сделкой**
   - Не покупать/ребалансировать, если ожидаемое преимущество < `2 * fee + gas + slippage_buffer`.
   - Иначе бот «крутит» капитал в минус на комиссиях.

2. **Уменьшить churn у ботов**
   - Привязать продажу ботов к рыночному условию (`P_spot > P_twap * (1 + x)`),
   - а не просто к балансовому порогу > 200 токенов.

3. **Арбитраж только при net-profit > 0 после всех издержек**
   - Сейчас проверка слишком мягкая для реального рынка.

4. **Обязательный LP-реинвест только из реализованной прибыли**
   - Не из основного оборотного капитала owner,
   - иначе NAV будет проседать даже при росте резерва пула.

5. **Риск-контур**
   - Лимит дневного убытка,
   - лимит числа сделок за цикл,
   - stop на период при ухудшении `K`/`STS`.

## 3) Практический целевой профиль (стартовый)

- `buyback_pol`: 0.1 .. 0.2
- `rebalance_pol`: 0.0 .. 0.2
- `arb_probe_pol`: 0.1 .. 0.3
- `bot_sell_amount`: 20 .. 40
- `bot_sell_threshold`: >= 260
- `lp_reinvest_owner_matic`: 0.0 на этапе стабилизации PnL

После выхода в устойчивый плюс включать LP-реинвест как долю от **положительной** realized PnL.

## 4) Как проверять перед live

- Прогон `simulate_our_robot_150.py` на 150 циклов.
- Затем `optimize_robot_profitability.py` для подбора параметров.
- Условие перехода в live:
  - 3+ независимых прогона с разными seed,
  - положительный PnL,
  - рост обоих LP-резервов,
  - ограниченная просадка.
